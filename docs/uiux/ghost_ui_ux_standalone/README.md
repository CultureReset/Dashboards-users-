# Ghost UI/UX Standalone HTML Prototype

Every HTML page in this folder now has its CSS and JavaScript embedded directly inside the file.

That means:
- No external styles.css dependency
- No external app.js dependency
- Each page can be opened by itself and still render correctly
- Mobile responsive CSS is included inside every page
- Interactive JavaScript is included inside every page

Start with:
- index.html — sign in
- signup.html — account creation
- onboarding.html — business/source discovery
- dashboard.html — owner dashboard
- business-data.html — real data modules
- apps.html — Ghost App Store
- app-install.html — app install flow
- connections.html — API/Composio/MCP Connections
- connection-setup.html — connection setup
- android.html — Android integrations/devices
- android-setup.html — Android integration setup
- automations.html — automation marketplace
- automation-setup.html — automation install/configuration
- marketplace.html — unified marketplace shell
- qr-menu-builder.html — Lovable-style QR Menu builder
- public-qr-menu.html — standalone QR Menu
- public-profile.html — public profile composer
- activity.html — approvals, verification, receipts
- developer-portal.html — SDK / publisher portal
- workspace-settings.html — settings
- architecture.html — architecture visualization

All page-to-page links still work when the folder is kept together.
